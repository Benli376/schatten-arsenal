# Schatten-Arsenal 0.7.0 – Minecraft Java 26.2 (Fabric)

Eigener Kreativ-Reiter, neun schwarz-violette Ausruestungsgegenstaende und drei Spezial-Boss-Eier.

- Alle Werkzeuge und Ruestungsteile sind unzerstoerbar.
- Gute Vanilla-Verzauberungen auf Stufe 50 (kein Fortune/Glueck, kein Frostlaeufer, keine Flueche).
- Vollstaendige Ruestung gibt zehn positive Effekte und entfernt viele negative.
- Boss-Eier fuer Schatten-Wither, Schatten-Warden und Schattenritter.
- Bossleisten, violette Partikel, erhoehte Lebenspunkte und spezielle Effekte.

## Installation
In das Fabric-26.2-Profil den fertigen JAR-Artefakt und die passende Fabric API in den mods-Ordner kopieren.
Nicht die Quellcode-ZIP als Mod installieren. In Creative: Reiter *Schatten-Arsenal*.

## Befehle
- `/function shadow:give/all`
- `/function shadow:summon/wither`
- `/function shadow:summon/warden`
- `/function shadow:summon/knight`

Die Mod wird in GitHub Actions kompiliert. Der Build ist kein Beweis fuer einen erfolgreichen Minecraft-Spieltest.
